# AIT (AppImage Integration Tool)
A cli tool that makes installing and managing AppImages as easy as possible.

- Written in C
- Minimal Dependencies
- No GUI
- Intuitive and easy to use

*Note: AIT is not nearly finished, and is currently a work in progress. Not currently functional*

# Usage
For detailed usage information, read the [Usage Guide](docs/usage.md).

## Examples
Installing an app:
```
ait install app.AppImage
```

list installed appimages:
```
ait installed
```

Update an app:
```
ait update app
```

Update all apps:
```
ait update
```
