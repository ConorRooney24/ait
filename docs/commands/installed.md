## Installed Command

The installed commaned can be used to list currently installed AppImages

## Synopsis
```
ait [GLOBAL OPTIONS] installed [COMMAND OPTIONS]
```

The installed command does not take any operands.

## Command Options

### -s, --short
Lists less information per record.

## Example Usage
List all installed AppImages.
```
ait installed
```

List all installed AppImages in short format.
```
ait installed -s
```
